# Snake Game (React Native) 🐍

A beginner-level Snake game built using React Native as part of a hands-on learning exercise. This project focuses on implementing core game mechanics and understanding real-time updates in a mobile environment.

## 🚀 Features
- Gesture-based snake movement  
- Dynamic snake growth after eating food  
- Boundary-aware movement within the game area  
- Real-time state updates and rendering  

---

## 🧠 Learnings
Through this project, I explored:

- Handling user gestures in React Native  
- Managing continuous movement (game loop logic)  
- Updating UI based on changing state  
- Structuring a simple interactive mobile application
